# ShambaLink UI design system

Source: UI/UX Pro Max agriculture/farm-tech design-system search (Organic Biophilic; Feature-Rich Showcase).

## Direction

A calm, editorial farm-tech interface that feels practical, local, and modern. Use warm off-white surfaces, deep leaf-green actions, harvest gold accents, generous rounded panels, and restrained elevation. Product imagery uses soft harvest landscapes; the hero includes a small Three.js field illustration.

## Tokens

- Primary: #236B48; deep: #17472F; secondary leaf: #78A967
- Warm canvas: #F7F7F2; paper: #FFFFFF; border: #E4E9DF
- Harvest accent: #BD8C3B; muted text: #758176
- Display: Manrope; interface/body: DM Sans
- Corner radius: 12px controls, 17-22px cards
- Space rhythm: 8, 12, 16, 24, 32, 48, 64px

## Motion and accessibility

Use short entrance transitions for meaningful UI changes, subtle card hover feedback, and gentle 3D pointer response. Avoid continuous decorative animation. The Three.js scene observes prefers-reduced-motion and renders a static frame when reduced motion is requested. Buttons and form fields have visible keyboard focus, labels are explicit, icon-only controls have accessible names, and layouts collapse to a single column on small screens.
